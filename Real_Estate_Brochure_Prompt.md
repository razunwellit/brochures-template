# Prompt: Create a Premium 10-Page Real Estate Brochure (HTML5 + CSS3)

Design and develop a **premium, print-ready, luxury real estate
brochure** using **HTML5 and CSS3**.

The brochure should be designed as a **10-page A4 Portrait brochure**
that can later be exported to PDF or printed. The code should be clean,
modular, and easy to integrate into a Laravel or WordPress application
where all content will be populated dynamically.

## General Requirements

-   Use **HTML5** and **CSS3** only.
-   Create a **single HTML file** with a reusable stylesheet.
-   Each brochure page should be wrapped inside its own `<section>`
    element.
-   Use `page-break-after: always;` so each section prints on a separate
    A4 page.
-   Design specifically for **A4 Portrait**.
-   Follow modern UI/UX principles with a premium real estate aesthetic.
-   Use semantic HTML.
-   Keep the layout modular and reusable.
-   Write clean, well-structured, and commented code.
-   Avoid inline CSS whenever possible.
-   The template should be optimized for future dynamic integration.

-   **#000000**: primary text.

## Typography

Use modern system fonts with a clear hierarchy for titles, headings,
prices, captions, and body text.
